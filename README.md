# 羊羹手帖

羊羹の味わいを「特徴」と「個人的な評価」に分けて記録する、iPhone優先の軽量PWAです。

## 評価設計

### 味わいプロファイル（良し悪しではない）
- 甘さ
- 豆・素材の香り
- 濃厚さ
- かたさ
- なめらかさ
- 余韻

### 個人的な評価（高いほど自分にとって良い）
- 素材の風味
- 甘味のバランス
- 舌触り・食感
- 後味
- また食べたい
- 総合評価

## 記録項目
- 商品名
- 和菓子屋
- 食べた日
- 購入・入手した場所
- 羊羹の種類
- 主な風味・素材
- 食べた温度
- 切る厚さ
- 合わせた飲み物
- 写真（最大3枚・端末内で縮小）
- コメント
- 断面・見た目メモ

## デザイン
- タイトル: Yuji Syuku 400
- 本文・主要UI: Shippori Mincho B1 400/600
- くすみブラウン＋生成りの和紙調
- iPhone縦画面・片手操作を優先
- 過度な丸角、影、カードUI、グラデーションを避ける

## 保存方式
記録はブラウザの IndexedDB に保存されます。外部サーバーには送信しません。
写真も端末ブラウザの保存領域に入るため、Safariのサイトデータ削除・アプリ削除等で消える可能性があります。

## 起動方法
ローカルでは、このフォルダで静的Webサーバーを起動してください。

```bash
python3 -m http.server 8080
```

その後 `http://localhost:8080` を開きます。

iPhoneで恒久利用する場合は、GitHub Pages / Cloudflare Pages 等のHTTPS環境へ配置し、Safariの「ホーム画面に追加」を利用できます。

## バックアップ
「評価の見方」タブから、記録・写真を含むJSONバックアップを書き出し／読み込みできます。
